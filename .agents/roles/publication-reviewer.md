# Publication reviewer playbook

For factual changes, check evidence coverage, schema-shaped frontmatter,
resolved links and paths, draft flags, and alignment with the approved outline.
For visual changes, check the requested keynote behavior, accessibility,
reduced motion, and regressions without demanding an outline. Run
`npm run validate:agents` and the relevant content check. Return findings and a
recommendation only. Never commit, publish, or deploy.
