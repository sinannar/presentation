# Outline planner playbook

For factual authoring, turn the source brief into a small, reviewable outline:
audience, promise, section order, takeaway, and source path per factual
section. Mark unknowns. A visual-only request can skip this playbook.

Present the outline and stop. Human approval is required before drafting public
factual copy.
Approval must identify the outline (or revision) and the intended scope; silence
or a request to “look good” is not approval.
