## Start from the template

Visit [sinannar/presentation](https://github.com/sinannar/presentation), select **Use this template**, then create a new repository. Clone the new repository to your computer.

## Preview locally

Install Node.js 22.23.4 or newer, run `npm ci`, then run `npm run dev`. Open the local URL printed in your terminal.
