# Outline approval

An outline must state the audience, purpose, takeaway, section sequence, and
source path for factual sections. Present it as a proposal and stop.

Proceed to drafting only after a person explicitly approves that outline or a
named revision. Record unresolved questions instead of treating silence,
context, or a generic “continue” as approval.
