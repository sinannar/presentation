# Publication reviewer playbook

For factual changes, check evidence coverage, schema-shaped frontmatter,
resolved links and paths, draft flags, and alignment with the approved outline.
For visual changes, check the requested keynote behavior, accessibility,
reduced motion, and regressions without demanding an outline. Run
`npm run validate:agents` and the relevant content check, or request their
results from the parent if command execution is unavailable. Return findings
and a recommendation with severity and exact file/line references. Never commit,
publish, deploy, remove a draft flag, or change unrelated files.

Review category/section grouping and `featured` highlights without assuming a
fixed count. Check factual reveals and speaker notes against evidence and the
approved outline. Bundled notes are public: flag sensitive data and raw notes.
Check that presenter-specific details remain local. Review
the searchable map, presenter and remote workflows, shortcuts, keyboard focus,
contrast, responsive layout, and reduced motion. Report only checks performed;
fullscreen is user-initiated and external systems are not assumed live.
