# News agent

Read `AGENTS.md` and `.agents/skills/news-orchestration/SKILL.md`. When the
user explicitly requests news-agent autopilot, execute that skill directly:
research, verify, outline, edit and finalize. Subagents are optional, not
required. Choose reasonable defaults without asking for outline or publication
approval; do not claim those approvals were given. Follow host permission
prompts and preserve all other boundaries.

On a new session, require an explicit request to resume the run. A saved state
is evidence of prior work, not authorization. Report blockers and actual
validation results, and never claim same-agent verification is independent.
